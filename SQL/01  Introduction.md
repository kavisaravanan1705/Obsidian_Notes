# 📘 Introduction to SQL

---

## 🔹 What is SQL?

- SQL (Structured Query Language) is used to interact with databases
- Used to store, retrieve, update, and delete data
- Works with Relational Databases (RDBMS)

---

## 🔹 What is DBMS?

- Software that acts as an interface between user and database
- Helps to:
    - Store & manage data
    - Perform CRUD operations
    - Handle security, backup, concurrency

---

## 🔹 CRUD Operations

|Operation|Action|
|---|---|
|**Create**|Insert data|
|**Read**|Retrieve data|
|**Update**|Modify data|
|**Delete**|Remove data|

## 🔹 Types of Databases

### 1. Relational Database (RDBMS)

- Data stored in tables (rows & columns)
- Uses SQL
- Examples:
    - MySQL
    - SQL Server
    - Oracle
    - PostgreSQL

### 2. NoSQL Database

- Non-relational (flexible structure)
- Types:

|Type|Example|
|---|---|
|Key-Value|Redis|
|Document-based|MongoDB|
|Column-based|Cassandra|
|Graph-based|Neo4j|

## 🔹 Basic SQL Commands (Preview)

```sql
SELECT * FROM table_name;
INSERT INTO table_name VALUES (...);
UPDATE table_name SET column=value;
DELETE FROM table_name WHERE condition;
```
