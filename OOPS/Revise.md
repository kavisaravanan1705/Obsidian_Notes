### **How to upload future changes**

Whenever you add or modify notes in Obsidian, open Command Prompt in your vault folder and run these 3 commands:

```
git add .
git commit -m "Updated notes"
git push
```

|Command|Purpose|
|---|---|
|`git add .`|Stages your new and modified notes|
|`git commit -m "Updated notes"`|Saves a version of your changes|
|`git push`|Uploads the changes to GitHub|
