# Odd Occurring Element in O(log N) using Binary Search

## Problem

Given a sorted array:

- Every element appears exactly twice.
- Only one element appears once.
- Find that odd occurring element.

### Example

Input:

```text
1 1 2 2 3 4 4
```

Output:

```text
3
```

---

# Key Observation

## Before the Odd Element

Pairs start at EVEN indices.

```text
Index : 0 1 2 3 4 5 6

Array : 1 1 2 2 3 4 4
         ↑ ↑ ↑ ↑
```

Pairs:

```text
(0,1)
(2,3)
```

Notice:

```text
arr[0] == arr[1]
arr[2] == arr[3]
```

---

## After the Odd Element

Pattern shifts.

```text
3 4 4
```

Now pair starts at:

```text
5,6
```

which is an ODD index.

This shift helps Binary Search find the odd element.

---

# Binary Search Logic

## Step 1

Find middle index.

```java
mid = (low + high) / 2;
```

---

## Step 2

Make mid EVEN.

```java
if(mid % 2 == 1)
{
    mid--;
}
```

Why?

```text
Pairs normally start at even indices.
```

---

## Step 3

Compare

```java
arr[mid]
```

with

```java
arr[mid + 1]
```

---

### Case 1

```java
arr[mid] == arr[mid + 1]
```

Pair is correct.

Odd element is on the RIGHT side.

```java
low = mid + 2;
```

---

### Case 2

```java
arr[mid] != arr[mid + 1]
```

Pair is broken.

Odd element is on the LEFT side (or at mid).

```java
high = mid;
```

---

# Dry Run

Array:

```text
Index : 0 1 2 3 4 5 6

Array : 1 1 2 2 3 4 4
```

---

## Iteration 1

```text
low = 0

```

```text

```

Make even:

```text

```

```text

```

Equal.

Move right:

```text

```

---

## Iteration 2

```text

```

```text

```

Make even:

```text
mid = 4
```

Check:

```text
arr[4] = 3
arr[5] = 4
```

Not equal.

Move left:

```text
high = 4
```

---

## Iteration 3

```text

high = 4
```

Stop.

Answer:

```text
arr[4]
```

```text
3
```

# Java Code

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for(int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int low = 0;
        int high = n - 1;

        while(low < high) {

            int mid = (low + high) / 2;

            if(mid % 2 == 1) {
                mid--;
            }

            if(arr[mid] == arr[mid + 1]) {
                low = mid + 2;
            }
            else {
                high = mid;
            }
        }

        System.out.println(arr[low]);
    }
}
```

---

# Time Complexity

```text
O(log N)
```

Reason:

```text
Binary Search halves the search space every iteration.
```

---

# Space Complexity

```text
O(1)
```

---

# Memory Trick

```text
Before odd element:
Pairs start at EVEN index

After odd element:
Pairs start at ODD index
```

Check:

```java
arr[mid] == arr[mid + 1]
```

```text
Yes → Move Right

No → Move Left
```

Final answer:

```java
arr[low]
```
