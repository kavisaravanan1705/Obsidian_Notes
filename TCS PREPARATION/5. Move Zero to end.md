# Chocolate Packets — Move Zeros to End

## Problem
Move all `0`s to the end of the array while maintaining the relative order of non-zero elements.

### Example

Input:
```text
1 0 2 0 3
```

Output:
```text
1 2 3 0 0
```

---

# Logic (Two Pointers)

## Pointer Roles

- `i` → Position where the next non-zero element should be placed.
- `j` → Scans the entire array.

## Steps

1. Start `i = 0`, `j = 0`
2. Traverse the array using `j`
3. If `arr[j] != 0`
   - Swap `arr[i]` and `arr[j]`
   - Increment `i`
4. Increment `j` every iteration
5. Continue until `j < n`

---

# Dry Run

Array:
```text
[1, 0, 2, 0, 3]
```

| i | j | Action | Array |
|---|---|---------|--------|
| 0 | 0 | Non-zero, swap | [1,0,2,0,3] |
| 1 | 1 | Zero, skip | [1,0,2,0,3] |
| 1 | 2 | Non-zero, swap | [1,2,0,0,3] |
| 2 | 3 | Zero, skip | [1,2,0,0,3] |
| 2 | 4 | Non-zero, swap | [1,2,3,0,0] |

Final Output:
```text
1 2 3 0 0
```

# Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] arr = new int[n];

        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        int i = 0;
        int j = 0;

        while (j < n) {
            if (arr[j] != 0) {
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
                i++;
            }
            j++;
        }

        for (int k = 0; k < n; k++) {
            System.out.print(arr[k] + " ");
        }
    }
}
```

# Python Code

```python
n = int(input())
arr = list(map(int, input().split()))

i = 0
j = 0

while j < n:
    if arr[j] != 0:
        arr[i], arr[j] = arr[j], arr[i]
        i += 1
    j += 1

print(*arr)
```

# Memory Trick

```text
i = Place Pointer
j = Search Pointer

j finds non-zero elements.
i places them at the front.
```

When you see:

```text
Move zeros to end
Maintain order
```

Think:

```text
Two Pointers
i = place
j = search
```
