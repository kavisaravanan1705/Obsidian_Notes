# Bubble Sort (TCS NQT PYQ)

## Problem

Sort the array in ascending order using Bubble Sort.

### Example

Input:

```text
4 2 5 1 3
```

Output:

```text
1 2 3 4 5
```

---

# Core Idea

Compare adjacent elements.

```text
If Left > Right
    Swap
```

Keep repeating until the array becomes sorted.

---

# Why Called Bubble Sort?

The largest element moves to the end after each round.

Like a bubble rising to the top.

Example:

```text
4 2 5 1 3
```

After Round 1:

```text
2 4 1 3 5
        ↑
Largest element reached the end
```

# Easy Meaning of

```java
j < n - i - 1
```

Think:

```text
After every round,
one largest element reaches its correct position.

Don't check it again.
```

So the checking area becomes smaller.

Example:

| Round | Elements Checked |
|---------|---------|
| 1 | 4 2 5 1 3 |
| 2 | 4 2 5 1 |
| 3 | 4 2 5 |
| 4 | 4 2 |

# Easy Bubble Sort (Easy to Remember)

```java
for(int i=0;i<n-1;i++){

    for(int j=0;j<n-1;j++){

        if(arr[j] > arr[j+1]){

            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;

        }
    }
}
```

# Optimized Bubble Sort

```java
for(int i=0;i<n-1;i++){

    for(int j=0;j<n-i-1;j++){

        if(arr[j] > arr[j+1]){

            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;

        }
    }
}
```

# Java Code

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int[] arr = new int[n];

        for(int i=0;i<n;i++){
            arr[i] = sc.nextInt();
        }

        for(int i=0;i<n-1;i++){

            for(int j=0;j<n-i-1;j++){

                if(arr[j] > arr[j+1]){

                    int temp = arr[j];
                    arr[j] = arr[j+1];
                    arr[j+1] = temp;

                }
            }
        }

        for(int i=0;i<n;i++){
            System.out.print(arr[i] + " ");
        }
    }
}
```

# Python Code

```python
n = int(input())

arr = list(map(int,input().split()))

for i in range(n-1):

    for j in range(n-i-1):

        if arr[j] > arr[j+1]:
            arr[j], arr[j+1] = arr[j+1], arr[j]

print(*arr)
```
