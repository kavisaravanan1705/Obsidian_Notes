# 

## Problem

Count how many times each number appears in the array.

### Example

Input:

```text
6
1 2 1 3 2 1
```

Output:

```text
1:3 2:2 3:1
```

---

# What is HashMap?

HashMap stores data in:

```text
Key → Value
```

For Frequency Count:

```text
Number → Count
```

Example:

```text
1 → 3
2 → 2
3 → 1
```

---

# Important Functions

## put()

```java
map.put(key, value);
```

Stores or updates data.

Example:

```java
map.put(1, 3);
```

Map:

```text
{1=3}
```

---

## get()

```java
map.get(key);
```

Returns the value of the key.

Example:

```java
map.get(1);
```

Output:

```text
3
```

---

## getOrDefault()

```java
map.getOrDefault(key, defaultValue);
```

Meaning:

```text
If key exists → return its value
Else → return default value
```

Example:

```java
map.getOrDefault(5, 0);
```

If 5 is not present:

```text
0
```

---

# Most Important Line

```java
map.put(num, map.getOrDefault(num, 0) + 1);
```

Read it as:

```text
Get current count of num.
If num is not present, use 0.
Add 1.
Store it back.
```

# Printing the Result

```java
for(int key : map.keySet()) {
    System.out.print(key + ":" + map.get(key) + " ");
}
```

## keySet()

```java
map.keySet()
```

Returns all keys.

Example:

```text
{1=3, 2=2, 3=1}
```

Keys:

```text
1 2 3
```

Loop visits:

```text
key = 1
key = 2
key = 3
```

---

## map.get(key)

Returns the value of the current key.

Example:

```java
map.get(1)
```

returns:

```text
3
```

Output:

```text
1:3 2:2 3:1
```

# Java Code

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        HashMap<Integer, Integer> map = new HashMap<>();

        for(int i = 0; i < n; i++) {

            int num = sc.nextInt();

            map.put(num, map.getOrDefault(num, 0) + 1);
        }

        for(int key : map.keySet()) {

            System.out.print(key + ":" + map.get(key) + " ");
        }
    }
}
```

# Memory Trick

```text
put()            → Store / Update
get()            → Retrieve value
getOrDefault()   → Get value or return 0
keySet()         → Get all keys
```

Frequency Count Pattern:

```java
map.put(num, map.getOrDefault(num, 0) + 1);
```

Meaning:

```text
Increase frequency of num by 1.
```
