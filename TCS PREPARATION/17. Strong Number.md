# Armstrong Number Check

## Logic
- Store original number.
- Find each digit.
- Calculate factorial of each digit.
- Add all factorials.
- If sum == original number → Armstrong (as per given example).
- Else → Not Armstrong.

> Note: The examples are actually for a **Strong Number**, not a traditional Armstrong Number.

## Java Code

```java
import java.util.*;

public class Main {
    static int factorial(int n) {
        int fact = 1;
        for (int i = 1; i <= n; i++) {
            fact *= i;
        }
        return fact;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int num = sc.nextInt();
        int original = num;
        int sum = 0;

        while (num > 0) {
            int digit = num % 10;
            sum += factorial(digit);
            num /= 10;
        }

        if (sum == original)
            System.out.println("Yes");
        else
            System.out.println("No");
    }
}
```

## Example

**Input**
```
145
```

**Output**
```
Yes
```

**Input**
```
123
```

**Output**
```
No
```

## Complexity
- **Time:** O(N)
- **Space:** O(1)

## Pattern
```
Digit → Factorial → Add
Sum == Number ? Yes : No
```
