# GCD and LCM (Subtraction Method)

## Logic
- If numbers are equal, that number is the GCD.
- Subtract the smaller number from the larger number until both become equal.
- LCM = (a × b) / GCD

## Java Code

```java
import java.util.*;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int a = sc.nextInt();
        int b = sc.nextInt();

        int num1 = a;
        int num2 = b;

        while (a != b) {
            if (a > b)
                a = a - b;
            else
                b = b - a;
        }

        int gcd = a;
        int lcm = (num1 * num2) / gcd;

        System.out.println(gcd + " " + lcm);
    }
}
```

## Dry Run

**Input**
```text
12 18
```

```text
18 - 12 = 6
12 - 6 = 6

Both numbers = 6
```

```text
GCD = 6
LCM = (12 × 18) / 6 = 36
```

## Output

```text
6 36
```

## Complexity

- **Time:** O(max(a,b))
- **Space:** O(1)

## Pattern

```text
If a > b → a = a - b
Else      → b = b - a

Repeat until a == b

GCD = a
LCM = (num1 × num2) / GCD
```
