# 1. Java Array Reversal (Placement Notes)

## Problem

Reverse an array.

Example:

```text
Input:  1 2 3 4 5
Output: 5 4 3 2 1
```

---

# Method 1: Print in Reverse (Easy)

## Code

```java
import java.util.*;

class Main {
    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int arr[] = new int[n];

        for(int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        for(int i = n - 1; i >= 0; i--) {
            System.out.print(arr[i] + " ");
        }
    }
}
```

## How it works

Array:

```text
1 2 3 4 5
```

Indexes:

```text
0 1 2 3 4
```

Loop:

```java
for(int i = n-1; i >= 0; i--)
```

Values of `i`:

```text
4 3 2 1 0
```

Prints:

```text
5 4 3 2 1
```

## Important

✅ Easy for beginners  
❌ Does NOT actually reverse the array, only prints in reverse.

# Method 2: Swap Method (Placement Preferred)

## Idea

Swap:

- first ↔ last
    
- second ↔ second last
    

Example:

```text
1 2 3 4 5
```

Swap:

```text
1 ↔ 5
2 ↔ 4
```

Result:

```text
5 4 3 2 1
```

---

# Full Code

```java
import java.util.*;

class Main {
    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int arr[] = new int[n];

        for(int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        for(int i = 0; i < n/2; i++) {
            int temp = arr[i];
            arr[i] = arr[n - 1 - i];
            arr[n - 1 - i] = temp;
        }

        for(int i = 0; i < n; i++) {
            System.out.print(arr[i] + " ");
        }
    }
}
```

---

# Doubt 1: Why temp?

Wrong way:

```java
arr[0] = arr[4];
arr[4] = arr[0];
```

Array:

```text
1 2 3 4 5
```

Step 1:

```java
arr[0] = arr[4]
```

Becomes:

```text
5 2 3 4 5
```

Old `1` is lost.

So save it:

```java
int temp = arr[0];
```

Then:

```java
arr[0] = arr[4];
arr[4] = temp;
```

Final:

```text
5 2 3 4 1
```

---

# Doubt 2: Why n/2?

Because only HALF swaps are needed.

Example:

```text
1 2 3 4 5
```

Swaps:

```text
0 ↔ 4
1 ↔ 3
```

Middle stays same:

```text
2
```

`n = 5`

```text
5/2 = 2
```

Only 2 swaps needed.

---

# Doubt 3: Why not i < n?

If:

```java
for(int i=0; i<n; i++)
```

After first 2 swaps:

```text
5 4 3 2 1
```

Then loop continues.

`i = 3`  
Swaps again:

```text
2 ↔ 4
```

Undo happens.

Final becomes:

```text
1 2 3 4 5
```

So:

```java
i < n/2
```

Only reverse once.

---

# Doubt 4: What is n-1-i?

It finds opposite index.

Formula:

```java
n - 1 - i
```

Example:  
`n = 5`  
Indexes:

```text
0 1 2 3 4
```

When `i=0`

```java
5-1-0 = 4
```

Swap:

```text
0 ↔ 4
```

When `i=1`

```java
5-1-1 = 3
```

Swap:

```text
1 ↔ 3
```
