# Reverse Words in a Sentence

## Problem
Given a sentence, reverse the order of words.

### Example

Input:
```text
I love code
```

Output:
```text
code love I
```

---

## Logic

1. Read the sentence.
2. Split the sentence into words using space.
3. Traverse the words array from last to first.
4. Print each word.

---

## Dry Run

Input:
```text
hello world
```

Split:
```text
[hello] [world]
```

Traverse from end:

```text
world
hello
```

Output:
```text
world hello
```

---

## Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        String str = sc.nextLine();

        String[] words = str.split(" ");

        for(int i = words.length - 1; i >= 0; i--) {
            System.out.print(words[i] + " ");
        }
    }
}
```

---

## Key Points

### Read Input
```java
String str = sc.nextLine();
```
Reads the entire sentence.

### Split Words
```java
String[] words = str.split(" ");
```
Converts sentence into words array.

Example:
```text
"I love code"
↓
["I", "love", "code"]
```

### Reverse Traversal
```java
for(int i = words.length - 1; i >= 0; i--)
```

Starts from last word and moves backward.

---

## Complexity

- Time Complexity: O(N)
- Space Complexity: O(N)

---

```text

```
