
# Repeating Element in Array

> **Tags:** #dsa #arrays #hashing #duplicates #java  
> **Difficulty:** Easy  
> **Topic:** Arrays, Hashing

---

## 🧩 Problem Statement

Given an array of integers, identify the **repeating (duplicate) element**.

### Example

```
Input:
6
1 2 3 4 2 5

Output:
Repeat element: 2
```

---

## 🔵 Approach 1 — Brute Force

### Algorithm

1. Traverse the array using an outer loop.
2. Compare each element with all subsequent elements using an inner loop.
3. If a match is found, that element is the duplicate.

### Code

```java
import java.util.*;
class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int arr[] = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (arr[i] == arr[j]) {
                    System.out.println("Repeat element: " + arr[i]);
                    return;
                }
            }
        }
    }
}
```

### Complexity

|Metric|Value|
|---|---|
|⏱ Time|O(n²)|
|🗂 Space|O(1)|

### 🗣 Interview Explanation

> Uses nested comparison — each element is checked against all subsequent elements. Simple to implement but **inefficient for large inputs** due to quadratic time complexity.

---

## 🟢 Approach 2 — Optimized (HashSet)

### Algorithm

1. Initialize an empty `HashSet`.
2. Traverse the array.
3. If the current element **already exists** in the set → it's the duplicate.
4. Otherwise, **add it** to the set and continue.

### Code

```java
import java.util.*;
class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int arr[] = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }
        HashSet<Integer> set = new HashSet<>();
        for (int i = 0; i < n; i++) {
            if (set.contains(arr[i])) {
                System.out.println("Repeat element: " + arr[i]);
                return;
            }
            set.add(arr[i]);
        }
    }
}
```

### Complexity

|Metric|Value|
|---|---|
|⏱ Time|O(n)|
|🗂 Space|O(n)|

### 🗣 Interview Explanation

> Leverages `HashSet` for near **constant-time lookup** (O(1) average). Significantly faster than brute force, making it the **preferred interview approach**.
