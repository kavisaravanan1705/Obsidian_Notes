# Factory Production (Rate Calculation)

## Logic

- Production is directly proportional to days.
- Find units produced per day.
- Multiply by required days.

## Formula

```text
Units per day = X / 24

Production in D days = (X × D) / 24
```

## Java Code

```java
import java.util.*;

class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int x = sc.nextInt(); // units in 24 days
        int d = sc.nextInt(); // required days

        int result = (x * d) / 24;

        System.out.println(result);
    }
}
```

## Dry Run

### Input

```text
240 8
```

```text
Units per day = 240 / 24 = 10

Production in 8 days
= 10 × 8
= 80
```

### Output

```text
80
```

## Complexity

- **Time:** O(1)
- **Space:** O(1)

## Pattern

```text
Given:
X units → 24 days

1 day  → X/24 units

D days → (X × D)/24 units
```
