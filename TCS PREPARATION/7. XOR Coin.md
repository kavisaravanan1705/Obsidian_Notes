# XOR Coin Denomination

## Problem

A shopkeeper has coins of several denominations.

- Every denomination originally appeared an **even number of times**.
- One coin is lost.
- Find the denomination of the lost coin.

### Example

Input:
```text
5
2 3 2 4 4
```

Output:
```text
3
```

---

# Key Concept: XOR (^)

## XOR Rules

### Rule 1

```text
a ^ a = 0
```

Examples:

```text
1 ^ 1 = 0
2 ^ 2 = 0
5 ^ 5 = 0
```

### Rule 2

```text
0 ^ a = a
```

Examples:

```text
0 ^ 5 = 5
0 ^ 7 = 7
```

---

# Why XOR Works

Suppose coins are:

```text
2 3 2 4 4
```

XOR all elements:

```text
2 ^ 3 ^ 2 ^ 4 ^ 4
```

Group equal numbers:

```text
(2 ^ 2) ^ (4 ^ 4) ^ 3
```

Apply Rule 1:

```text
0 ^ 0 ^ 3
```

Apply Rule 2:

```text
3
```

Answer:

```text
3
```

---

# How to Calculate XOR

Example:

```text
5 ^ 7
```

Convert to binary:

```text
5 = 101
7 = 111
```

Perform XOR:

```text
  101
^ 111
-----
  010
```

Rule:

```text
Same      → 0
Different → 1
```

Column-wise:

```text
1 ^ 1 = 0
0 ^ 1 = 1
1 ^ 1 = 0
```

Result:

```text
010
```

Convert to decimal:

```text
010 = 2
```

Therefore:

```text
5 ^ 7 = 2
```

# Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int xor = 0;

        for (int i = 0; i < n; i++) {
            xor = xor ^ sc.nextInt();
        }

        System.out.println(xor);
    }
}
```

# Memory Trick

```text
Same number XOR Same number = 0

a ^ a = 0
0 ^ a = a
```

Therefore:

```text
All pairs disappear.
Only the unique/missing element remains.
```
