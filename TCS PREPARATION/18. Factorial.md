# Factorial in Java

## Definition
Factorial of a number `n` is the product of all numbers from `1` to `n`.

```text
n! = 1 × 2 × 3 × ... × n
```

## Examples

```text
0! = 1
1! = 1
4! = 4 × 3 × 2 × 1 = 24
5! = 5 × 4 × 3 × 2 × 1 = 120
```

## Java Code

```java
static int factorial(int n) {
    int fact = 1;

    for (int i = 1; i <= n; i++) {
        fact *= i;
    }

    return fact;
}
```

## Dry Run: factorial(4)

```text
fact = 1

i = 1 → fact = 1
i = 2 → fact = 2
i = 3 → fact = 6
i = 4 → fact = 24

return 24
```

## Complexity

- **Time:** O(N)
- **Space:** O(1)

## Pattern

```text
Initialize fact = 1
Loop from 1 to n
Multiply fact by i
Return fact
```
