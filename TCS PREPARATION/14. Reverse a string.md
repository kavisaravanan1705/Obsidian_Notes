# Reverse a String (Characters)

## Problem
Reverse all characters in a string.

### Example

Input:
```text
hello
```

Output:
```text
olleh
```

---

## Logic

1. Start from the last character.
2. Move towards the first character.
3. Print each character.

---

## Dry Run

Input:
```text
hello
```

Characters:
```text
h e l l o
```

Reverse Traversal:
```text
o l l e h
```

Output:
```text
olleh
```

---

## Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        String str = sc.nextLine();

        for(int i = str.length() - 1; i >= 0; i--) {
            System.out.print(str.charAt(i));
        }
    }
}
```

---

## Key Points

### Length of String

```java
str.length()
```

Returns total characters.

Example:
```text
hello → 5
```

### Access Character

```java
str.charAt(i)
```

Example:
```java
str.charAt(0) → h
str.charAt(4) → o
```

### Reverse Loop

```java
for(int i = str.length()-1; i >= 0; i--)
```

Traverses from last character to first.

---

## Complexity

- Time Complexity: O(N)
- Space Complexity: O(1)

---

## Shortcut

```text
Start from end → Print each character
```

Template:

