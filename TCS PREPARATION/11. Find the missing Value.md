# Find Missing Number in 1 to N+1

## Problem

Array contains N distinct numbers from:

```text
1 to N+1
```

Exactly one number is missing.

Find the missing number.

---

# Example 1

Input:

```text
3
1 2 4
```

Expected numbers:

```text
1 2 3 4
```

Present:

```text
1 2 4
```

Missing:

```text
3
```

Output:

```text
3
```

---

# Main Logic (Sum Formula)

## Step 1

Find expected sum of numbers from:

```text
1 to N+1
```

Formula:

```text
n × (n+1) / 2
```

But here maximum number is:

```text
N+1
```

So:

```text
Expected Sum = (N+1)(N+2)/2
```

---

# Example

Input:

```text
3
1 2 4
```

N:

```text
3
```

Numbers should be:

```text
1 2 3 4
```

Expected Sum:

```text
4 × 5 / 2
```

```text
20 / 2
```

```text
10
```

---

## Step 2

Find actual array sum.

```text
1 + 2 + 4
```

```text
7
```

---

## Step 3

Subtract

```text
Missing Number
=
Expected Sum - Actual Sum
```

```text
10 - 7
```

```text
3
```

Answer:

```text
3
```

# Java Code

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        int actualSum = 0;

        for(int i = 0; i < n; i++) {
            actualSum += sc.nextInt();
        }

        int expectedSum = (n + 1) * (n + 2) / 2;

        System.out.println(expectedSum - actualSum);
    }
}
```

# Python Code

```python
n = int(input())

arr = list(map(int, input().split()))

actual_sum = sum(arr)

expected_sum = (n + 1) * (n + 2) // 2

print(expected_sum - actual_sum)
```

# Why This Works

Expected:

```text
1 + 2 + 3 + 4 + 5 + 6
```

Actual:

```text
1 + 2 + 3 + 5 + 6
```

Subtract:

```text
(1+2+3+4+5+6)
-
(1+2+3+5+6)
```

Everything cancels.

Only:

```text
4
```

remains.

# Pattern Recognition

Whenever you see:

```text
Numbers from 1 to N
One number missing
Find missing value
```

Think:

```text
Expected Sum - Actual Sum
```
