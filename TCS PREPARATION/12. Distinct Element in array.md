# Distinct Elements in Array (Java)

## Concept
Use a `HashSet` to store unique elements.
A `HashSet` does not allow duplicate values.

## Why `if (!set.contains(x))`?
- `HashSet` automatically ignores duplicates.
- But to **print distinct elements only once and in order**, we must check before printing.

## Template

```java
HashSet<Integer> set = new HashSet<>();

for(int i = 0; i < n; i++) {
    int x = sc.nextInt();

    if(!set.contains(x)) {
        System.out.print(x + " ");
        set.add(x);
    }
}
```

## Count Distinct Elements

```java
HashSet<Integer> set = new HashSet<>();

for(int i = 0; i < n; i++) {
    set.add(sc.nextInt());
}

System.out.println(set.size());
```

## Dry Run

Input:
1 2 1 3 2 4

Set Progress:
- 1 → {1}
- 2 → {1,2}
- 1 → Duplicate (Ignore)
- 3 → {1,2,3}
- 2 → Duplicate (Ignore)
- 4 → {1,2,3,4}

Distinct Elements:
1 2 3 4

Count:
4
