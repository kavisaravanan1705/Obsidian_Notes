# COVID Handshake Problem

## Problem

Given `N` people in a room.

Each person shakes hands with every other person exactly once.

Find the total number of handshakes.

---

# Understanding the Problem

## Example: 3 People

People:

```text
A B C
```

Handshakes:

```text
A-B
A-C
B-C
```

Total:

```text
3
```

---

## Example: 4 People

People:

```text
A B C D
```

Handshakes:

```text
A-B
A-C
A-D
B-C
B-D
C-D
```

Total:

```text
6
```

---

# Important Observation

Suppose:

```text
N = 5
```

Person 1 shakes with:

```text
4 people
```

Person 2 shakes with:

```text
4 people
```

Person 3 shakes with:

```text
4 people
```

Person 4 shakes with:

```text
4 people
```

Person 5 shakes with:

```text
4 people
```

Total:

```text
5 × 4 = 20
```

But wait!

Handshake:

```text
A-B
```

is counted twice:

```text
A shakes B
B shakes A
```

So divide by 2.

```text
20 / 2 = 10
```

Answer:

```text
10
```

---

# Formula

```text
Handshakes = N × (N - 1) / 2
```

# Java Code

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        long n = sc.nextLong();

        long handshakes = n * (n - 1) / 2;

        System.out.println(handshakes);
    }
}
```

# Memory Trick

```text
Everyone shakes with everyone else.

Total unique pairs:

N × (N - 1) / 2
```

Think:

```text
Choose any 2 people from N people

= N C 2

= N × (N - 1) / 2
```
