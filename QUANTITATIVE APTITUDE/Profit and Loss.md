## 1. CP = 100 Assumption Trick

> [!tip] When to use
> When **only percentage** is given and CP is not given.

**Concept:** Assume CP = 100, then calculate SP easily.

### Example 1 — 20% Profit
```
CP = 100
Profit = 20
SP = 120

CP : SP = 100 : 120 = 5 : 6
```

### Example 2 — 15% Loss
```
CP = 100
Loss = 15
SP = 85

CP : SP = 100 : 85 = 20 : 17
```

### Memory Table

| Profit % | CP : SP |
|----------|---------|
| 10%      | 10 : 11 |
| 20%      | 5 : 6   |
| 25%      | 4 : 5   |
| 50%      | 2 : 3   |

## 2. Successive Percentage Formula

> [!tip] When to use
> When **two profits** or **two losses** are given.

$$\text{Net Profit} = P_1 + P_2 + \frac{P_1 \times P_2}{100}$$

### Example — 20% and 10%
```
20 + 10 + (20×10)/100
= 30 + 2
= 32%
```

### Example — 30% and 20%
```
30 + 20 + (30×20)/100
= 50 + 6
= 56%
```

> [!warning] Common Mistake
> ❌ Wrong: 20 + 10 = 30
> ✅ Correct: 30 + 2 = **32**

## 3. Equal Profit and Loss Trick

> [!important] Golden Rule
> If **same percentage** profit and loss → **Always LOSS**

$$\text{Loss \%} = \frac{P^2}{100}$$

### Example — 20% profit then 20% loss
```
20×20 / 100 = 4%  →  Loss = 4%
```

### Example — 10% increase then 10% decrease
```
10×10 / 100 = 1%  →  Loss = 1%
```

### Memory Table

| Equal % | Loss |
|---------|------|
| 10%     | 1%   |
| 20%     | 4%   |
| 30%     | 9%   |
| 40%     | 16%  |
| 50%     | 25%  |

## 4. Ratio Method

> [!tip] When to use
> When profit or loss percentage is given — convert directly to ratio.

### Profit Examples
```
Profit = 25%  →  Assume CP = 100, SP = 100 + 25 = 125  →  Ratio = 4 : 5
Profit = 20%  →  CP = 100, SP = 120  →  Ratio = 5 : 6

Ratio : CP : SP
100 : 125 
4 : 5
```

### Loss Examples
```
Loss = 20%  →  CP = 100, SP = 80  →  Ratio = 5 : 4
```

### Memory Table

| %   | Profit CP:SP | Loss CP:SP |
|-----|-------------|------------|
| 10% | 10 : 11     | 10 : 9     |
| 20% | 5 : 6       | 5 : 4      |
| 25% | 4 : 5       | 4 : 3      |
| 50% | 2 : 3       | 2 : 1      |

### Classic Placement Model — Two items, same SP

```
Profit case:  CP:SP = 5:6  →  SP 120 → 240,  CP = 200
Loss case:    CP:SP = 5:4  →  SP 80  → 240,  CP = 300

Total CP  = 200 + 300 = 500
Total SP  = 240 + 240 = 480
Loss      = 20
Loss %    = 20/500 × 100 = 4%
```

> [!tip] Super Shortcut
> Same % profit and loss → Loss = P²/100

## 5. Discount Formula

> [!tip] When to use
> When **MP** and **discount** are given.

$$\text{SP} = \frac{MP \times (100 - \text{Discount})}{100}$$

### Examples

**MP = 1000, Discount = 20%**
```
SP = 1000 × 80/100 = 800
```

**MP = 500, Discount = 10%**
```
SP = 500 × 90/100 = 450
```

**MP = 1000, Discount = 20%, Profit = 25%**
```
SP = 1000 × 80/100 = 800
CP = 800 × 100/125 = 640
```

### Important Formulas

| Case       | Formula                        |
|------------|-------------------------------|
| Profit case | CP = SP × 100 / (100 + P)   |
| Loss case   | CP = SP × 100 / (100 − L)   |

## 6. False Weight Trick

> [!tip] When to use
> When seller gives **less quantity**.

$$\text{Profit \%} = \frac{\text{Error}}{\text{Given Weight}} \times 100$$

$$\text{Error} = \text{True Weight} - \text{Given Weight}$$

### Examples

**900g instead of 1kg**
```
Error = 1000 − 900 = 100
Profit = 100/900 × 100 = 11.11%
```

**800g instead of 1kg**
```
Error = 200
Profit = 200/800 × 100 = 25%
```

**750g instead of 1kg**
```
Error = 250
Profit = 250/750 × 100 = 33.33%
```

**950g instead of 1kg**
```
Error = 50
Profit = 50/950 × 100 = 5.26%
```

### Memory Table

| Given | Profit   |
|-------|----------|
| 900g  | 11.11%   |
| 800g  | 25%      |
| 750g  | 33.33%   |
| 666g  | 50%      |

## 7. SP Based Profit Conversion

> [!tip] When to use
> When **profit is given on SP** (not CP).

$$\text{Profit on CP} = \frac{P}{100 - P} \times 100$$

### Examples

**20% on SP**
```
20 / 80 × 100 = 25%
```

**25% on SP**
```
25 / 75 × 100 = 33.33%
```

### Memory Table

| SP Profit | CP Profit |
|-----------|-----------|
| 10%       | 11.11%    |
| 20%       | 25%       |
| 25%       | 33.33%    |
| 50%       | 100%      |

## 8. Increase and Decrease Concept

### Successive Change Formula Table

| Case                    | Formula                  |
|-------------------------|--------------------------|
| Increase then Increase  | x + y + xy/100           |
| Decrease then Decrease  | x + y − xy/100           |
| Increase then Decrease  | x − y − xy/100           |
| Decrease then Increase  | y − x − (x×y)/100        |

### Formula — Increase then Decrease

$$\text{Net} = x - y - \frac{xy}{100}$$

**20% increase → 10% decrease**
```
20 − 10 − 2 = 8% increase
```

**30% increase → 20% decrease**
```
30 − 20 − 6 = 4% increase
```

**Same % (e.g., 20% increase then decrease)**
```
20×20/100 = 4% loss
```

### Formula — Decrease then Increase

$$\text{Net} = \text{Increase} - \text{Decrease} - \frac{\text{product}}{100}$$

**20% decrease → 30% increase**
```
30 − 20 − 6 = 4% increase
```

**40% decrease → 50% increase**
```
50 − 40 − 20 = −10  →  10% loss
```

## 11. Profit or Loss Decision Rule

> [!important]
> - **Positive result** → Profit
> - **Negative result** → Loss
> - **SP > CP** → Profit
> - **CP > SP** → Loss

### Examples
```
40 − 25 − 10 = +5   →  Profit ✅
30 − 40 − 12 = −22  →  Loss ✅
```

### Final Universal Rule Example

**Increase 25%, Decrease 30%**
```
25 − 30 − 7.5 = −12.5  →  12.5% Loss
```
